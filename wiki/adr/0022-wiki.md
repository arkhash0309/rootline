# 0022 — Wiki: in-repo `wiki/` plus the `rootline-wiki` skill

Status: accepted
Date: 2026-11-26

## Context

AI coding agents implement the whole project and have no memory between sessions. They need a persistent record of what is true now and why, and human reviewers need the decision trail. A wiki inside the repository is versioned with the code and visible to reviewers.

This decision is row 0022 of the ADR index in spec §3. Primary reason recorded there: Portable across agents; visible to reviewers.

## Decision

Wiki: In-repo `wiki/` plus project skill `.claude/skills/rootline-wiki`.

Spec §3 row 0022 is the source of this wording. It is implemented by requirement IDs WIK-001 to WIK-031.

## Consequences

- `task wiki:lint` runs in CI and fails on missing pages, broken links, forbidden words and stale status (WIK-021).
- Every PR that changes code paths updates the wiki (WIK-020).

## Alternatives considered

- External Notion or Confluence: not chosen because spec §3 requires a wiki that is portable across agents and visible to reviewers.

## Spec references

WIK-001 to WIK-031; spec §3 row 0022.
